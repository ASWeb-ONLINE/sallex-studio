# Бриф проекта Sallex Studio

Дата фиксации: 13 октября 2026 года, Europe/Moscow. Источник требований — предоставленное владельцем ТЗ; его неизмененная локальная копия перечислена в [реестре референсов](../references/README.md).

## Факты и утвержденные ограничения

Sallex Studio — собственный сайт студии по созданию сайтов. Владелец хочет освоить на нем весь рабочий цикл: подготовку, будущую разработку, публикацию и обновления до выполнения клиентских заказов. Состав команды и публичное представление автора не предоставлены.

Сейчас действует `PREPARATION_ONLY`: организация материалов, содержательные документы, минимальные настройки текста и безопасная локальная подготовка Git. Результат этапа — рабочая папка с сохраненным контекстом, а не готовый сайт или макет.

Не входят в текущий этап: код сайта, прототипы, новые изображения и логотипы, генератор приложения, `package.json`, установка зависимостей, сборка, GitHub Actions, деплой, регистрация домена, платные сервисы, аналитика и формы. Новый анализ нейминга, конкурентов, цен, продвижения и юридических вопросов не проводится.

Портфолио пока нет. Место для него описывается в структуре, но до появления реальных работ на публичном сайте не будет ни блока, ни пункта меню, ни заглушки «скоро». Нельзя придумывать проекты, отзывы, клиентов, награды, показатели, подтвержденные результаты или состав команды.

## Будущая работа с исходниками

- Один сайт — один отдельный репозиторий GitHub, непосредственно в редактируемой рабочей папке.
- Не создавать вторую экспортную копию и не строить процесс вокруг ZIP-архивов.
- GitHub рассматривается как хранилище исходников. Хостинг и способ публикации не выбраны; GitHub Pages не назначен.
- Сейчас запрещены создание удаленного репозитория, подключение origin, commit и push. Фактическое локальное состояние описано в [отчете](preparation-report.md).

## Предварительные гипотезы, не коммерческие обязательства

Небольшой и локальный бизнес — возможная первичная аудитория. Личные обращения — предполагаемый сценарий первых продаж. Это гипотезы для последующего уточнения владельцем, без нового маркетингового исследования на данном этапе.

Лендинг и сайт компании — предложенные форматы услуг. Не определены точный состав работ, цены, бюджет, сроки, гарантии, количество правок, порядок оплаты или условия сопровождения. В документах нет окончательных продающих текстов.

Рабочая задача будущей главной: понятно объяснить деятельность студии, показать подход и дать посетителю согласованный способ обсудить свой проект. Конкретный канал связи и текст основного действия еще не выбраны.
