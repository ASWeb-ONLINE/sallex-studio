# Проверка реализации — 15 октября 2026

Проверялась production-сборка на локальном HTTP preview с base `/sallex-studio/`. Публикация Pages отложена по прямому решению владельца; проверка работающего публичного URL не выполнялась. Результаты ниже относятся к реально запущенной локальной версии, а не к макетам.

## Среда и команды

Windows, Node 24.19.0, pnpm 11.25.0, Astro 7.3.8, TypeScript 6.0.3, Playwright 1.64.1, Chromium 156.0.8078.4. Для проверки доступности использован axe-core через @axe-core/playwright 4.13.0. Другие браузерные движки и физические телефоны не проверялись.

В окружении pnpm вызван через `node <bundled-pnpm.cjs>` без изменения PATH и глобальных настроек. Исполнены:

```sh
pnpm install --frozen-lockfile
node node_modules/astro/bin/astro.mjs check
node node_modules/astro/bin/astro.mjs build
node node_modules/@playwright/test/cli.js install chromium
node node_modules/astro/bin/astro.mjs preview --host 127.0.0.1 --port 4321
node node_modules/@playwright/test/cli.js test
node scripts/measure-build.mjs
```

Проверка Astro: 28 файлов, 0 ошибок, 0 предупреждений, 0 подсказок. Статическая сборка: главная и 404. Финальный локальный запуск Playwright: **20 passed, 0 failed, 0 skipped, 0 flaky**, 15,3 секунды; начало 05:42:09 UTC. Сырой JSON — `reports/local-only/e2e-results.json`, не коммитируется.

## Визуальные проходы и исправления

Первый проход: сохранены скриншоты; 16 из 19 тогдашних тестов прошли. На трех мобильных ширинах найден горизонтальный overflow: при скрытии `<br>` слова заголовка FAQ склеивались. Добавлены текстовые пробелы, восстановлены корректные переносы. Первый экран на desktop уплотнен по высоте, мелкие мобильные подписи увеличены. После исправлений второй проход: 20 из 20 тестов прошли.

Финальный проход дополнительно использует настоящую эмуляцию touch для tablet/mobile снимков. Исправлено возобновление tracking при возвращении разрешенных media-настроек, когда указатель уже внутри поверхности. Все 20 тестов повторно прошли. Просмотрены готовая настольная и мобильная страницы, графические слои и композиция. Цвет проявляется частично внутри схем, смысловой текст не зависит от наведения.
