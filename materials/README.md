## Правила дальнейшего пополнения

Сохранять оригиналы, отмечать источник и статус разрешения на публикацию. Не смешивать чужие референсы с утвержденными активами студии. Перед добавлением новых материалов проверять их содержимое и назначение; наличие файла само по себе не означает разрешения опубликовать его.

Для будущих непубличных материалов предусмотрено правило исключения `materials/local-only/` в `.gitignore`; сам этот дополнительный каталог сейчас не создан. Секреты, пароли и токены в материалы и документы не помещать. Необходимые решения имеют отдельные сроки в [реестре решений](../docs/decisions.md).
